This page is the canonical demo for the .content > nav.leftnav rail next to .content > aside. Three rails on desktop; when there is no room for all three, the left navigation moves behind the menu in the top bar.

Markup

<div class="content">
  <nav class="leftnav">…</nav>
  <main>…</main>
  <aside>…</aside>
</div>

Notes

  • Use .rail-section for grouped lists in either rail.
  • Section heading: <h3 class="eyebrow">.
  • For collapsible sections, wrap in <details> + <summary class="rail-section-summary"> and load rail.js to persist state.
